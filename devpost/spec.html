⏱️ Idle & Movement Finite State Machine (FSM)

The core stillness engine transitions between 4 deterministic states based on window events and timing thresholds:

ACTIVE_INPUT
User typing / clicking. Timer paused.
ACTIVE_STILLNESS
≥ 2000ms idle. Pulsing green pill.
STILLNESS_TICK
Every 1000ms: +1 pt to score & evaluate badges.
MOVEMENT_VIOLATION
Input during stillness! Scolding banner appears.
State: ACTIVE_INPUT — The default state when the user is interacting with inputs. Score accumulation is paused, and the movement reprimand is hidden.

💾 LocalStorage Schema Contract

Single immutable-style state object stored under lazylegend_state:

interface LazyLegendState {
  version: 1;
  score: number;             // Total Laziness Points (e.g., 250)
  totalIdleSeconds: number;  // Cumulative seconds spent in stillness
  longestStreak: number;     // Highest unbroken idle streak in seconds
  confessions: Array<{
    id: string;
    text: string;
    timestamp: number;
    pointsAwarded: number;
  }>;
  unlockedBadgeIds: string[]; // e.g., ["speed_overrated", "tomorrows_problem"]
  lastActiveTimestamp: number;
}

Corrupted State & Safe Fallback

If JSON parsing fails or the schema version does not match, StorageManager automatically loads the default zero-effort state without crashing:

const DEFAULT_STATE = {
  version: 1,
  score: 0,
  totalIdleSeconds: 0,
  longestStreak: 0,
  confessions: [],
  unlockedBadgeIds: [],
  lastActiveTimestamp: Date.now()
};
