✅ Verifiable Acceptance Criteria

Specific, observable behaviors testable by looking at the screen during the build:

1. Sloth Mode Idle Tracker

Leaving input untouched for 5 seconds adds exactly 5 points to the Laziness Score.
Timer displays unbroken idle minutes/seconds in real-time.

2. Cardinal Sin Movement Reprimand

Moving the mouse or pressing a key while in stillness pauses the timer and surfaces a sarcastic warning within 300ms.
Reprimand banner cleanly clears once stillness resumes.

3. Procrastination Confessional

Typing an avoided task and clicking "Postpone" logs the item, awards +50 pts, and bursts confetti.
Clicking "Roll Random Excuse" selects from 15+ absurd excuses, displays a typing reprimand, and awards +50 pts.

4. Badges & Milestone Rewards

30 seconds unbroken stillness unlocks "Speed Is Overrated".
Reaching 500 total points unlocks "Supreme Couch Commander".

5. 1-Click Clipboard Certificate

Clicking "Copy Certificate" copies formatted text with emojis, current score, and latest excuse to clipboard.
Copy button displays immediate confirmation ("Copied to Clipboard! 🦥").

6. Dynamic Leaderboard

When user score crosses 340 points, their position automatically hops above Alex Rivera.

🔄 States & Boundaries

State Trigger Observed UI Behavior
First Visit Fresh browser session Score is 0 pts (Level 1 Novice), all badges locked, confessional placeholder says "No effort detected yet. Excellent."
Active Stillness 2+ seconds with no mouse/keys Green status badge pulses, counter ticks up every second, +1 floating numbers climb.
Violation State Mouse movement or keypress Red reprimand banner appears, counter pauses, points stop accumulating.
Persistence Page refresh / reopen Current score, unlocked badges, and recent confessions are restored from localStorage.
Clipboard Fallback Clipboard permission denied Selectable modal text box pops up with "Press Ctrl+C to copy your certificate".

⚖️ Product Decisions & POC Boundaries

Decisions & Rationale

• Automatic Inactivity Tracking: Avoids requiring the user to click "Start" before slacking off—making inaction truly zero-effort.

• The Effort Paradox: Typing an excuse triggers the "Cardinal Sin" scolding for physical effort, but awards +50 pts bonus to heighten the comedic irony.

• Emoji Text Certificate: Output is optimized for immediate paste into Slack, Teams, and Discord without image file download friction.
